# 📈 Wikipedia Attention Shock Forecaster

A web-based machine learning application that predicts sudden spikes in Wikipedia page views (attention shocks) using historical traffic patterns and data-driven forecasting techniques. The application provides an interactive interface to fetch Wikipedia pageview data, preprocess the data, train forecasting models, and visualize future trends.

---

## 🌟 Project Overview

Wikipedia page views often experience unexpected surges due to breaking news, viral trends, and significant real-world events. These spikes, known as **attention shocks**, reflect sudden increases in public interest.

This project analyzes historical Wikipedia traffic data and applies machine learning techniques to forecast future page views and identify potential attention shocks.

---

## 🚀 Features

- 🌐 Interactive web-based application using Streamlit
- 📥 Automatic fetching of Wikipedia pageview data
- 🧹 Data preprocessing and cleaning
- 📊 Data validation and quality checks
- 🤖 Machine learning-based forecasting
- 📈 Visualization of historical and predicted trends
- ⚡ Detection of unusual spikes in attention
- 📦 Modular and reusable Python code

## 📊 How It Works

1. Enter a Wikipedia article title.
2. Fetch historical pageview data using the Wikipedia Pageviews API.
3. Validate and clean the dataset.
4. Preprocess the data for modeling.
5. Train forecasting models.
6. Generate future predictions.
7. Visualize trends and detect attention shocks.
